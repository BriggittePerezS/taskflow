# 🚀 TaskFlow Enterprise | Project Management System

¡Bienvenido a **TaskFlow Enterprise**! Esta no es una simple lista de tareas; es una plataforma integral de gestión de proyectos diseñada para equipos que buscan eficiencia, control de tiempos y una interfaz de usuario vanguardista.



## ✨ Características Principales

* **Gestión de Proyectos Full-Cycle:** Control total desde la creación hasta la finalización con estados personalizados (`Pendiente`, `En Progreso`, `Completado`).
* **Panel de Control (Dashboard):** Visualización de datos en tiempo real con KPIs de rendimiento.
* **Barra de Progreso Inteligente:** Algoritmo dinámico que calcula el cumplimiento de objetivos globales.
* **Calendario Operativo:** Visualización temporal de entregas para evitar saturación de carga de trabajo.
* **Asignación de Responsables:** Identificación clara de quién lidera cada frente de trabajo.
* **Control de Plazos:** Sistema de monitoreo con indicadores de fecha de inicio y fin.
* **Interfaz Cyber-Aqua:** Estética moderna con efectos de cristal (Glassmorphism) y modo oscuro optimizado.

## 🛠️ Tecnologías Utilizadas

* **React 18** - Biblioteca principal para la interfaz.
* **TypeScript** - Para un código robusto y libre de errores de tipo.
* **Tailwind CSS** - Estilizado de última generación.
* **Lucide React** - Set de iconos profesionales.
* **Framer Motion** - Animaciones suaves y transiciones de estado.
* **LocalStorage API** - Persistencia de datos local sin necesidad de base de datos externa.
